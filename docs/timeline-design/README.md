# Project timeline — designed version

The eight-page A4 timeline (`../Exchequer-Project-Timeline.pdf`) and its source.

- `gen.py` writes the eight pages from the figures in `../project-timeline.md`;
  `python3 gen.py` rebuilds them into `project/`.
- `*.dc.html` + `canvas.json` are the pages as they sit on the Claude Design canvas
  (https://claude.ai/artifact/XScTnjQztDNmpTEJvqf4Fo), where they can be edited and
  exported with Export PDF → All artboards.
